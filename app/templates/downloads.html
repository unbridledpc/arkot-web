Game client

ArkOT uses the open-source mehah OTClient with modern 15.25 assets.

  1. Download the latest client from mehah/otclient releases (Windows & Linux builds).
  2. Start it once — it downloads the 15.25 assets automatically.
  3. On the Enter Game screen enable HTTP login and set the server to
    http://{{ game_host }}:{{ login_port }}/login, client version 15.25.
  4. Log in with your email and account password.

A preconfigured ArkOT client bundle is coming — until then the four steps above get you in.
