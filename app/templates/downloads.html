{% endcall %} {% call box('Getting started') %}
  1. Create an account, then create a character.
  2. Unpack the download into a folder of your own — not inside the archive, and not in Program Files.
  3. Start Arkenfall.exe (Windows) or ./arkenfall (Linux). The first start asks to download the game graphics; say yes and wait for the bar to fill.
  4. On the Enter Game screen the server is already selected. Log in with your e-mail address and your account password.

Setting it up by hand instead? HTTP login, server http://{{ game_host }}:{{ login_port }}/login, client version 15.25.

{% endcall %} {% call box('What you are downloading') %}

The Arkenfall client is a build of OTClient, the free open-source game client, under the MIT licence — the licence and credits ship inside the folder. Arkenfall brands it, fills in the server, and carries a handful of interface fixes. It ships no bot module: the rules ban automation, so the official download does not hand you one.
