Arkenfall is played with the free, open-source mehah OTClient using the modern 15.25 graphics. It runs on Windows and Linux.

  1. Download the latest release from mehah/otclient releases.
  2. Start it once; it fetches the 15.25 assets on its own.
  3. On the Enter Game screen enable HTTP login, set the server to http://{{ game_host }}:{{ login_port }}/login and the client version to 15.25.
  4. Log in with your email and account password.

A preconfigured Arkenfall client bundle is in preparation. Until then these four steps get you in.
